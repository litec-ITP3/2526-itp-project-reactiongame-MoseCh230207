# Concept - `ReactionGame`
## Documentation:
1. Problem Description:
    - two Persons play on a MicroConroller (Pico W/ Arduino)
    - Goal of the game is to test the Reaction-Time.
    - Both Players do have a button and press if a certain Signal is shown (Light/ Noise) 
2. Tasks (used Technologies):
    - What do we need (Micro-Controller, Notebook for the WebApp, Buttons for the Micro-Controller)?
    - Used Programming-Language: C (because it´s fast), HTML/CSS/JavaScript
    - Libraries: `Arduino.h` (in the Sketch there is only "Arduino-Core", so you don´t need any extra `C`-libraries), node
    - Software-Development of the Program
    - The Micro-Controller sends the Data to the WebApp



## Our Concept:
- PICO gets Data from the buttons -> sends it to the Server -> Server displays them on the Website
