# Installation 
- Needed Hardware: RasperryPi-PICO, Three Buttons (blue, red and orange)
- Needed Software: Node.js, VSCode, ArduinoIDE
- Needed Libraries: `Arduino.h` (in the Sketch there is only "Arduino-Core", so you don´t need any extra `C`-libraries), node
- Note: Don´t forget to install `Node.js` and the necessary Node-Modules for the `express.js`-Server (INTO THE `ENDPRODUCT`-FOLDER)

- Get the Repo on your Computer (by `git clone ...`), then go to the `ENDPRODUCT` Folder and look at `manual.pdf`
